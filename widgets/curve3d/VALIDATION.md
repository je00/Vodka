## 复现

在本目录（仓库的 `widgets/curve3d`）执行：

```powershell
node tests/core.test.js
python tests/protocol_test.py
```

第一项需要 Node.js，第二项仅需 Python 标准库，会对两种协议和三种轨迹数执行六组短暂的本地 UDP 回环测试。

可选 Qt 测试需要 PyQt5：

```powershell
python -m pip install PyQt5
python tests/qt_smoke.py
```

它会重新生成本目录的 preview.png。`tests/qt_stub` 是用于测试的最小替代接口，**不能复制到 VOFA+ 的插件目录**。

## 实际边界

- Qt 自动测试中的 `MyModules`、通道和 `sys_manager` 由测试替代对象提供，验证真实 QML 的加载、计算和生命周期；实际主程序验证是另行完成的界面与数据输入检查。
- 目标 API 按官方 Qt 5.14.2 控件文档和上游示例实现；自动测试环境为 Qt 5.15.2。Qt 5.15 的 Connections 旧语法弃用提示不影响运行，保留该写法是为了兼容官方 Qt 5.14 控件模式。
- 已在 VOFA+ 1.3.10 内完成拖入、九通道绑定、实际 UDP JustFloat 三条同时显示、两条/三条切换、旋转，以及正常关闭重启后的显示数、绑定、视角恢复和重新接收。串口及实际 MCU 联调尚未完成。
- C99 示例未在目标编译器或 MCU 上编译；需要接入设备实际的通信驱动。异步/DMA 发送必须使用具有足够生命周期的缓冲区。
- 公开宿主接口只提供每次刷新后的通道最新值；本插件不能保证高速通信帧逐点无损保留。

## 用户安装后的验收

1. 插件出现在控件列表中，可以拖入，并通过“显示轨迹数”选择 1、2 或 3 条。
2. 运行 `python examples/demo_sender.py --curves 3 --rate 20`，将 1/2/3 组分别绑定 I0～I2、I3～I5、I6～I8，看到青色、橙色、粉色三条轨迹。
3. 旋转、缩放、平移及 XY/XZ/YZ 切换正常。
4. 切为 2 条时仅显示前两条，第三条停止采样；恢复为 3 条后第三条从新段继续，自动适配覆盖当前显示轨迹。
5. 暂停时各条点数保持不变，恢复后另起一段。
6. 清空全部后从新数据开始；改变一条的通道仅清空该条，不影响其余轨迹。
7. 正常关闭再打开，显示条数、九个通道绑定、位置和视角恢复，历史轨迹为空。
